# Hello World

One shared three-color selector for a browser, portable Windows Electron app, Chromium side panel and Firefox sidebar. Selecting red, blue or green immediately changes Hello World; fresh sessions start red.

[Download releases](https://github.com/pchemguy/SDD-Manager-Demo-Hello-ChatGPT-Autodoc-AIO-3in1-V1/releases) and follow [installation instructions](docs/INSTALL.md). Packages bundle their runtime assets and require no separate Node.js, development server or backend. Windows is an unsigned portable development package; both extensions are development packages, with temporary loading for unsigned Firefox.

See [development and checks](docs/DEVELOPMENT.md), [project scope](docs/dev/PROJECT.md) and [task evidence](docs/dev/TASKS.md). Native Windows launch and native sidebar events remain unverified in this Linux environment; exact feasible checks and exclusions are documented.

Development uses [SDD Manager](SDD-MANAGER.md). See [AI disclosure](AI_DISCLOSURE.md).
